# Horse vs Rose Tic Tac Toe

A polished browser-based Tic Tac Toe game built with HTML, CSS and JavaScript.

The game includes local multiplayer, three computer difficulty levels, match scoring and a responsive interface while keeping the original Horse vs Rose visual theme.

## Live Demo

[Play Horse vs Rose](https://rpath97.github.io/TicTacToe-js/)

## Features

- Play against the computer or another player
- Easy, Medium and Hard computer difficulty
- Hard mode uses Minimax
- Single game, Best of 3 and Best of 5 match formats
- Round and match score tracking
- Winning-cell highlighting
- Responsive layout for desktop, tablet and mobile
- Sound toggle
- Victory animation and audio feedback
- Accessible board controls and status messaging
- Restart round and return-to-menu controls

## Difficulty Levels

**Easy** chooses from available moves at random.

**Medium** looks for winning moves, blocks immediate losses, prefers the center and corners, and remains beatable.

**Hard** uses the Minimax algorithm to choose the strongest available move.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Minimax algorithm
- GitHub Pages

## Run Locally

Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/rpath97/TicTacToe-js.git
cd TicTacToe-js
```

No build step or package installation is required.
